# SVG 애셋 제작 브리프 — 해산물과 소고기의 게임 공방

산출 파일: `js/art.js` 한 개. 전역 `const ART = { tree, stump, axe, saw, twinSaw, silverSaw, goldSaw, avatar, corridor, door }`.
각 값은 완결된 `<svg>...</svg>` 문자열. 키 이름 변경 금지.

---

## 1. 용도 · 사용자 · 렌더 조건

**용도** — 초등 1·3학년 두 어린이가 종이에 그린 게임 기획서를 그대로 옮긴 웹 게임 2편의 화면 그림.
현재는 임시 도형(원 3개짜리 나무, 라운드렉트 아바타)과 단색 아이콘 2종(`axe`/`saw`)으로 도구 5종을 돌려막고 있어 상점에서 도끼 말고는 전부 같은 그림이다. 이걸 교체한다.

**보는 사람** — 게임을 기획한 두 어린이, 같은 반 아이들, 교사(전자칠판). 어린이 본인이 "내가 그린 게 저기 있다"를 알아봐야 한다.

**렌더 환경**
- 크롬북 1366×768, 스크롤 없음. 무대(`.stage`)는 약 1300×400 (16:9~3:1 사이 가변).
- 나무캐기 무대는 왼쪽 필드 약 1000×400 + 오른쪽 상점 300px 고정. 1180px 이하에서 상점 250px.
- 배경색: 무대 하늘 `#dcefff`→`#f3f9ff`, 땅 `#8fd08a`→`#6fb96d`, 상점/카드 `#fff`, 사이트 도화지 `#f3eee4`.

**실제 계산된 렌더 크기** (CSS 확인값 — 지시서의 근사치보다 이쪽이 정확)

| 애셋 | 실제 크기 | 비고 |
| --- | --- | --- |
| `tree` | 220×280 (1180px 이하 160×280) | `.wc-tree-wrap` width 220px, height 70% |
| `stump` | 84×63 | width 84px, 높이 자동 |
| 도구 5종 (상점) | 약 25px | `.wc-item-ico` font-size 22px × `.ico` 1.15em |
| 도구 5종 (보유 칩) | 약 13.5px | `.wc-tool` 13.5px × `.ico.sm` 1em |
| `avatar` | 101×168, 이동 중 50×84 | height 42%, aspect 120/200, `.walk`에서 scale(.5) |
| `corridor` | 1300×400 (무대 전체) | 무대 비율 따라 가로가 늘고 준다 |
| `door` | 약 143×151 (좁은 화면에선 110×151까지) | `.esc-back` 그리드 1fr 열 |

도구 아이콘의 실제 최소 크기는 **13.5px**이다. 22px가 아니라 13.5px에서 5종이 구분돼야 한다. 이게 이 브리프에서 제일 어려운 요구다.

## 2. 스타일 가이드

### 톤
정돈된 **플랫 벡터**. 아이가 크레용으로 잡은 색·비례·실루엣은 그대로 두되, 삐뚤빼뚤한 선과 칠 삐짐은 정리한다.
- 크레용 질감은 **테두리 선의 성격**으로만 남긴다. 손그림 느낌의 살짝 굵은 진한 갈색/먹색 외곽선 + 균일한 면 채색.
- 노이즈 텍스처·필터로 크레용 질감을 흉내내지 않는다 (filter 금지이기도 하다).

### 금지
- 큰 눈·볼터치·반짝이·말풍선·이모지 같은 캐릭터화. 나무와 그루터기에 얼굴 금지.
- 플래시게임 톤: 형광 원색, 두꺼운 검정 아웃라인(3px+ 상당), 강한 베벨·유광 하이라이트, 드롭섀도 남발.
- 사실적 3D 셰이딩, 다단계 그라데이션 음영, 사진 같은 나뭇결 묘사.
- 아이 원화에 없는 요소 추가 (새, 구름, 꽃, 별, 배경 소품).

### 선 · 모서리 규칙
- 외곽선은 면 색보다 어두운 **같은 계열** 색. 순검정(`#000`) 금지.
- 굵기는 **화면에서 1.2~2px로 보이도록** viewBox 단위로 환산해 지정한다.
  - `tree` (viewBox 세로 260 → 화면 280): stroke-width 1.5~2
  - `corridor` (viewBox 1300 → 화면 1300): stroke-width 2~3
  - 도구 (viewBox 24 → 화면 13.5): stroke는 되도록 쓰지 말고 **면(fill)으로 형태를 만든다.** 꼭 필요하면 1 이하는 금지, 최소 1.
- `stroke-linejoin="round"`, `stroke-linecap="round"` 기본.
- 모서리는 얕게 둥글게. 반지름은 짧은 변의 4~8%. 알약 모양(`rx`=높이 절반) 금지 — 아이 그림이 각진 크레용 선이다.
- 같은 애셋 안에서 stroke 굵기는 최대 2종.

### viewBox 규격 (고정)
| 키 | viewBox | preserveAspectRatio | 이유 |
| --- | --- | --- | --- |
| `tree` | `0 0 140 260` | 기본(생략) | 가로 비율 0.538. 220px·160px 두 폭 모두에서 **높이가 제약**이 되어 밑동이 항상 땅에 닿는다. 이보다 넓으면 좁은 화면에서 나무가 공중에 뜬다 |
| `stump` | `0 0 80 60` | 기본 | 현행 유지 |
| 도구 5종 | `0 0 24 24` | 기본 | 5개 전부 동일 |
| `avatar` | `0 0 120 200` | 기본 | `.esc-avatar`의 aspect-ratio와 일치 |
| `corridor` | `0 0 1300 400` | **`none`** | 무대 폭 변화 흡수 |
| `door` | `0 0 96 160` | **`none`** | 그리드 열 폭 변화 흡수 |

## 3. 애셋별 스펙

### 3.1 `tree` — 나무 (viewBox 0 0 140 260)
원화: 가는 세로 갈색 줄기가 화면 아래까지 쭉 내려오고, 그 위에 초록 뭉게구름 잎이 얹혀 있다. 잎은 줄기보다 조금 넓을 뿐 크지 않다. 잎 안쪽으로 줄기가 비쳐 보인다.

- **밑동은 `y=260`에 정확히 닿게.** 잘림 없이, 여백 없이.
- **줄기 중심선은 `x=70`.** `.wc-tree-wrap`의 `transform-origin: 50% 100%`으로 82도 회전(넘어짐)하므로 밑동 중앙이 viewBox 중앙 하단과 일치해야 회전이 자연스럽다.
- 줄기 폭 28~34, 아래로 갈수록 아주 살짝 넓어짐(원화의 크레용 획 느낌). 줄기 세로 결선 2~3개.
- 잎 덩어리는 `y=10 ~ y=120` 사이, 폭 120 이내. 원화처럼 **가로로 넓지 않은 세로 뭉치**. 뭉게구름 실루엣은 원호 6~9개를 이은 **단일 path**로 그리고 그 위에 그늘 덩어리 1개, 밝은면 1개만 얹는다 (임시본처럼 circle 5개 겹치기 금지 — 회전 시 원끼리 어긋나 보인다).
- 잎이 줄기를 가로지르는 지점(원화의 특징)을 살려, 잎 하단에서 줄기가 살짝 비어져 나오게.
- **회전 내성**: 82도 회전 후에도 형태가 성립해야 한다. 좌우 비대칭 요소(한쪽으로 튀어나온 가지 등) 금지, 밝은면은 잎 위쪽 중앙 부근에만.
- 그림자 없음. CSS가 `drop-shadow`를 이미 얹는다.
- 팻말은 그리지 않는다 (`.wc-sign`이 DOM). 나무 상단 `y<10` 영역은 팻말이 겹칠 수 있으니 비워 둔다.

### 3.2 `stump` — 그루터기 (viewBox 0 0 80 60)
원화: 줄기와 같은 갈색의 짧은 기둥, 위가 둥글다.

- 윗면 타원(절단면 살구 `#D9A67E`) + 옆면 기둥(줄기 갈색). 나이테는 링 1~2개, 완전한 동심원 말고 살짝 치우치게.
- 밑동 `y=60`에 닿게. 폭 52~60.
- 84px로 렌더되므로 나이테 선 굵기는 최소 1.5 단위.
- 나무와 **같은 갈색 계열·같은 외곽선 두께**를 써서 한 벌로 보이게.

### 3.3 도구 5종 (viewBox 0 0 24 24 · 13.5px에서 구분)
원화: 상점 표에 도끼 100 / 톱 200 / 쌍톱 606(규칙은 600) / 은톱 720 / 금톱 800.

한 벌로 보이게 하는 공통 규칙:
- 같은 외곽선 색 `#3B3730`, 같은 나무 손잡이 색, 같은 대각선 축(왼쪽 아래 → 오른쪽 위 45도).
- 여백: 상하좌우 1.5단위 안쪽에 그림이 들어가게.
- **fill 위주.** 13.5px에서 stroke 1단위는 0.56px이라 흐려진다.

구분은 **색만으로 하지 않고 실루엣으로 먼저 한다** (13.5px에서는 색보다 실루엣이 먼저 읽힌다):

| 키 | 실루엣 | 색 | 13.5px 구분 근거 |
| --- | --- | --- | --- |
| `axe` | 삼각 도끼날 1개 + 곧은 자루 | 강철 + 나무 | 톱류와 실루엣이 완전히 다름 |
| `saw` | 직선 날 1장 + 권총형 나무 손잡이 | 강철 + 나무 | 기준형 |
| `twinSaw` | **평행한 날 2장** (약간 벌어진 V), 손잡이 1개 | 강철 + 나무 | 날 개수 |
| `silverSaw` | **닫힌 프레임(활톱)** 형태 — ㄷ자 프레임 + 그 안에 날 | 전체 은색, 나무 없음 | 프레임 실루엣 + 밝은 은색 |
| `goldSaw` | 활톱 프레임 + **두꺼운 등날**(spine) | 전체 금색 | 프레임 + 진한 금색 |

- 은톱/금톱은 실루엣이 같으므로 **명도 차를 크게** 벌린다. 은은 밝고 차갑게(`#E4EAF0`), 금은 어둡고 따뜻하게(`#E8B84B`). 흰 배경 `#fff` 위에서 은톱이 사라지지 않도록 은톱에는 반드시 `#A9B4C0` 그늘면을 넣는다.
- 톱니: 지그재그 path, 진폭 최소 2단위, 주기 3단위 이상, **이빨 5~6개까지만**. 그보다 잘면 13.5px에서 회색 뭉치가 된다.
- 그라데이션은 은톱·금톱에 각 1개까지 허용(금속감). 나머지 3종은 단색 면만.
- **통합 주의** — 현재 도구 아이콘은 `core.js`의 `icon()` 헬퍼가 `<path>` 조각을 `fill="currentColor"`로 감싸 쓴다. ART의 도구는 색을 가진 완결 `<svg>`라 이 경로를 못 탄다. `woodcut.js`에서 `icon(t.ico)` 대신 `ART[t.artKey]`를 직접 넣도록 배선해야 하고, `.wc-tool .ico { color: var(--c) }`는 무효가 된다. (배선은 이 브리프의 범위 밖 — 제작자는 이 사실만 알고 있으면 된다.)

### 3.4 `avatar` — 뒷모습 아바타 (viewBox 0 0 120 200)
원화: 검은 바가지머리(귀 아래까지 덮음), 연보라 긴팔 상의(엉덩이까지 오는 넉넉한 기장), 빨간 바지, 회색 신발. 팔은 몸에 붙어 아래로 내려와 있고 손만 살짝 보인다. 목은 거의 안 보인다.

- 원화의 비례를 지킨다: **머리가 크다.** 머리 높이가 전체의 약 28~30%, 상의가 약 30%, 바지+신발이 약 38%.
- 머리카락은 뒤통수를 덮는 반원+직선 밑단(바가지). 얼굴 안 보임 — 뒷모습이므로 이목구비 금지.
- 상의는 어깨가 각진 넉넉한 실루엣, 소매 끝에서 피부색 손이 조금.
- 발은 좌우로 살짝 벌어지게, 신발은 짧은 가로 블록.
- 밑에 얕은 타원 그림자(불투명도 0.15~0.2)를 넣어 바닥에 붙게 한다.
- **50×84px(이동 시 0.5배)에서도 검은 머리 / 보라 / 빨강 3색 블록이 읽혀야 한다.** 잔무늬·주름선 금지.
- 좌우 2도 기울임(`.lean-l/.lean-r`)이 걸리므로 좌우 대칭으로.
- 밑동은 `y=196` 부근, 하단 4단위는 그림자 여유.

### 3.5 `corridor` — 1점 투시 복도 (viewBox 0 0 1300 400, preserveAspectRatio="none")
원화: 노란 천장이 위쪽 쐐기, 좌우는 세로결 벽돌 주황 벽, 바닥은 초록이 앞으로 퍼지고, 정면에 문 2개와 초록 칠판이 붙은 벽.

**소실 사각형(반드시 이 좌표)** — `.esc-back`(left 28%, top 27%, width 44%, height 46%)과 정확히 맞춘다.
- 좌: `x=364`, 우: `x=936`, 상: `y=108`, 하: `y=292`.
- 천장: `(0,0) (1300,0) (936,108) (364,108)`
- 좌벽: `(0,0) (364,108) (364,292) (0,400)`
- 우벽: `(1300,0) (1300,400) (936,292) (936,108)`
- 바닥: `(0,400) (364,292) (936,292) (1300,400)`
- 뒷벽: `364,108` ~ `936,292` 사각형.

- **뒷벽도 이 애셋이 칠한다.** DOM `.esc-back`은 배경을 투명으로 바꿔 도어·칠판만 얹는 그릇이 된다(통합 시 필요한 CSS 변경 1줄 — 제작자는 뒷벽을 반드시 그려 넣을 것).
- 뒷벽 아래에 걸레받이 띠(`#7A5230`, 높이 6~8단위)를 `y=292` 기준으로.
- 벽돌: 원근에 맞춰 소실점(`x=650, y=200`) 쪽으로 수렴하는 가로선 + 세로 줄눈. 줄눈은 뒤로 갈수록 촘촘해진다. 벽돌 한 장을 개별 도형으로 그리지 말고, **수렴선 path 8~12개 + 세로 줄눈 조각**으로 암시한다(5KB 제한).
- 바닥: 소실점으로 수렴하는 결 4~6줄, 앞이 밝고(`#5DB06A`) 뒤가 어둡게(`#3F8A4C`). 그라데이션 1개까지 허용.
- **`preserveAspectRatio="none"` 대응** — 가로가 늘거나 줄어도 봐줄 만해야 한다:
  - 원·정원 금지(타원으로 찌그러진다).
  - 선 굵기는 세로선과 가로선이 서로 다르게 눌리므로, 얇은 선은 **면(사각형 path)** 으로 그려 굵기가 균등하게 스케일되게 한다.
  - 텍스트·문자 금지.
  - 무대 비율 3:1(1300×400)과 2.25:1(900×400) 양쪽에서 검수.
- 문과 칠판은 그리지 않는다 (DOM). 뒷벽은 균일한 면으로 두고 장식을 넣지 않는다.

### 3.6 `door` — 닫힌 문 (viewBox 0 0 96 160, preserveAspectRatio="none")
원화: 정면 벽에 붙은 파란 회색 문 2개, 세로로 숫자가 적혀 있고 위쪽에 문패 자리.

- 문틀(짙은 `#35506B`, 두께 3~4단위) + 문판(`#94B9D6`) + 안쪽 패널 홈 1~2개(`#7EA6C6`).
- 상단 모서리만 둥글게(`rx` 6 상당), 하단은 각지게 — 바닥에 닿는 문이다.
- **비워 둘 자리**
  - `y=12 ~ y=52`(높이의 8~32%), 좌우 전폭: DOM `.esc-plate`(흰 문패에 숫자)가 얹힌다. 이 띠에는 어떤 무늬도 넣지 않는다.
  - 오른쪽 `x=80~92`, `y=78~92`(높이 52% 부근): DOM `.esc-knob`(11px 원)이 얹힌다. 손잡이를 SVG에 그리려면 이 자리에 그리고 DOM 쪽 `.esc-knob`을 제거해야 하니, **SVG에는 그리지 않는 쪽을 기본으로** 한다.
- 하단은 `y=160`에 딱 맞게(문 아래가 벽에 잘려 들어가는 CSS 구조).
- 좌우로 늘어난다: 세로 홈은 두 줄까지만, 대각선 장식 금지.
- `.esc-door.open`에서 `rotateY(±75deg)`로 열리므로 문판이 좌우 어느 쪽 축으로 돌아도 성립하게 **좌우 대칭**으로.

## 4. 공통 기술 제약 (전부 필수)

1. **큰따옴표만.** JS 템플릿 리터럴(`` ` ``) 안에 들어가므로 백틱 금지. 속성값은 `"..."`. 작은따옴표도 쓰지 않는다(문자열 이스케이프 사고 방지).
2. `${` 시퀀스 금지 (템플릿 리터럴 보간으로 해석된다).
3. **외부 참조 금지** — `<image>`, `xlink:href`, 폰트, CDN, `url(...)` 외부 리소스 전부 금지. 사이트 전체가 외부 요청 0건이다.
4. **`<script>` · `<style>` · `<filter>` · `<mask>` · `<clipPath>` 금지.** 그림자·흐림은 반투명 도형으로만.
5. **`<text>` 금지** (폰트 의존 + corridor는 늘어난다). 모든 글자는 DOM이 얹는다.
6. **그라데이션은 애셋당 최대 1개.** `id`는 `art-tree-1`처럼 **애셋 이름 prefix로 전역 유일**하게. 10개 SVG가 한 DOM에 공존하므로 `id="g1"` 같은 건 충돌한다.
7. **개당 5KB 이하** (미압축 문자열 길이 기준). 전체 파일 40KB 이하 권장.
8. **애니메이션 금지** — `<animate>`, `<animateTransform>`, CSS 애니메이션 클래스 모두. 움직임은 CSS(`fall`, `grow`, `shake`, `walk`, `open`)가 담당한다.
9. `width`/`height` 속성 금지. `viewBox`만 둔다 (CSS가 100%로 채운다).
10. `aria-hidden="true"` 를 루트 `<svg>`에 붙인다. 접근성 텍스트는 DOM 쪽에 이미 있다.
11. 좌표는 소수점 1자리까지. 불필요한 자릿수로 용량 낭비 금지.
12. `fill="currentColor"` 사용 금지(다색 애셋). 모든 색은 hex 리터럴.

1. **방탈출 무대** — 홈 → 해산물 → 「곱셈 방탈출」 시작.

2. **나무캐기 무대** — 홈 → 소고기 → 「곱하기 나무캐기」 시작.
